# Review PR Comments

Follow the monorepo
[`/review-pr` workflow](../../../../.claude/commands/review-pr.md) for
`$ARGUMENTS` (a PR number or URL). It owns labels, thread triage, replies, the
release-note gate, and resolving threads.

Before pushing a fix, run this library's
[pre-commit checks](../../AGENTS.md#pre-commit-checklist).
